# sweet-help

참조 카드. 한 번 출력하고 끝, 모드 안 바꿈.

## 뭐 하나

스윗의 모든 강도, 형제 스킬, 끄는 방법, 그리고 환경변수나 설정 파일로 기본 강도를 바꾸는 방법을 한 장으로 출력한다. 한 번만 출력 — 활성 모드를 바꾸지 않고, 플래그 파일도 안 쓰고, 아무것도 남기지 않는다. 슬래시 커맨드를 잊었을 때 쓴다.

## 어떻게 켜나

```
/sweet-help
```

"스윗 도움말", "스윗 명령어 뭐 있어", "스윗 어떻게 써" 로도 켜진다.

## 출력 예시

```
강도:
  /sweet              full (기본)
  /sweet lite         약하게
  /sweet ultra        최대

스킬:
  /sweet-commit       짧은 한국어 커밋 메시지
  /sweet-review       한 줄 PR 코멘트
  /sweet-stats        세션 토큰 사용량

끄기:
  "스윗 끄기" / "그만" / "normal mode"
```
