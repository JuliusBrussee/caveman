---

다음 명령을 한국어로 한 번만 보여주고 현재 모드는 바꾸지 않는다.

- `/sweet lite|full|ultra`: 한국어 반말 강도 선택. 기본 full.
- `/sweet off`: 해제. `/sweet status`: 현재 상태 확인.
- `/sweet-commit`: 평문 한국어 Conventional Commits 메시지.
- `/sweet-review`: 평문 한국어 코드 리뷰.
- `/sweet-compress <파일>`: 최신 모체의 안전 검증을 거쳐 자연어 파일 압축.
- `/sweet-stats`: 모체 도구로 실제 사용량 확인. 한국어 절감률은 미측정.

내부 모드명 caveman은 full/lite, ultracave는 ultra. megacave도 한국어 ultra 호환 모드이며 중국어로 바꾸지 않는다. lite/full은 같은 저장 슬롯을 쓰고 강도는 대화 지시로 유지한다. 엔진·환경 변수·설정 경로는 모체 caveman 이름을 유지한다.
