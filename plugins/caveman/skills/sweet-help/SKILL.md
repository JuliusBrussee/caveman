  Show the Sweet command reference once. Use for /sweet-help or "스윗 도움말".
  Does not change or persist a mode.
---

Display this card in Korean once. Do not change the current mode or write state.

- `/sweet lite|full|ultra`: casual Korean intensity; default full.
- `/sweet off`, `/sweet status`: disable or inspect state.
- `/sweet-commit`: plain Korean Conventional Commits message.
- `/sweet-review`: plain Korean code-review comments.
- `/sweet-compress <file>`: compress a prose file with upstream safety validation.
- `/sweet-stats`: recorded usage; Korean savings are unmeasured.

Internal modes: caveman stores lite/full; ultracave stores ultra. megacave is a Korean ultra compatibility mode, never a switch to Chinese. lite/full share a stored slot; conversational instructions retain the chosen intensity. Engine packages, environment variables and state paths keep their upstream caveman names.
